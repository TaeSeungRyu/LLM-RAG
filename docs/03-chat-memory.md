# 03. 대화 메모리

## 개념
일반적인 Ollama Chat API 호출은 과거 요청을 자동으로 기억하지 않습니다. 이전 대화를 다시 보내야 문맥이 이어집니다.

## 목적
사용자와의 연속 대화, 프로그램 재시작 후 대화 이력 복원을 구현합니다.

## 동작 과정
```text
질문 → SQLite에서 이전 메시지 조회 → 메시지 배열 구성 → LLM 호출
     → 질문·답변을 SQLite에 저장
```

## 주요 Role
| Role | 의미 |
|---|---|
| `system` | 역할·행동 지침 |
| `user` | 사용자 메시지 |
| `assistant` | 모델 답변 |

## 핵심 요약
- `chat.db`에 저장한 기록은 재시작 후에도 남습니다.
- **DB에 저장**하는 것과 **LLM에 전달**하는 것은 별개입니다.
- 너무 긴 대화는 입력 길이 제한과 처리 비용을 고려해 일부만 전달합니다.
