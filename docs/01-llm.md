# 01. LLM

## 개념
LLM(Large Language Model)은 입력 문맥을 바탕으로 다음 토큰을 예측하며 텍스트를 생성하는 언어 모델입니다.

## 목적
질문 답변, 요약, 번역, 코드 생성 등 자연어 작업을 수행합니다.

## 동작 과정
```text
사용자 질문 → 프롬프트 구성 → LLM 처리 → 자연어 답변
```

## 핵심 요약
- 실습 모델: `qwen3:1.7b`
- LLM은 외부 DB를 자동으로 조회하지 않습니다. 필요한 자료를 직접 전달해야 합니다.
- 사실과 다른 답변을 그럴듯하게 생성하는 현상을 **Hallucination(환각)** 이라고 합니다.
