# RAG — Hybrid Search 요약

## 1. 핵심 개념

**Hybrid Search(하이브리드 검색)**는 **의미 기반 Vector Search**와 **키워드 기반 BM25 Search**를 함께 사용하는 RAG 검색 전략이다.

기존 Vector Search에 키워드 검색을 추가해 서로의 약점을 보완한다. 새로운 LLM이나 Embedding 모델을 뜻하는 것은 아니다.

## 2. Vector Search와 BM25 비교

| 구분 | Vector Search | BM25 Search |
|---|---|---|
| 검색 기준 | 문장의 의미 | 단어(키워드)의 중요도 |
| 주요 기술 | Embedding, Cosine Similarity | 단어 빈도, 희귀성, 문서 길이 보정 |
| 강점 | 표현이 달라도 의미가 비슷한 문서 검색 | 정확한 용어·오류 코드 검색 |
| 한계 | 정확한 단어나 식별자를 놓칠 수 있음 | 단어가 다르면 의미가 비슷해도 놓칠 수 있음 |

### 예시

질문: **"회사의 출근 시간은?"**

- **Vector Search**: "직원들은 오전 9시에 업무를 시작합니다."처럼 표현이 달라도 의미가 비슷한 문서를 찾는 데 유리하다.
- **BM25**: "출근 시간은 오전 9시입니다."처럼 검색어가 직접 포함된 문서를 찾는 데 유리하다.

## 3. Hybrid Search 처리 흐름

```text
사용자 질문
    ├─→ Vector Search (의미 검색) ─→ A, B, C
    └─→ BM25 Search   (키워드 검색) → C, D, A
                        ↓
                검색 결과 결합
                        ↓
               중복 제거: A, B, C, D
                        ↓
              순위 통합 (예: RRF)
                        ↓
                 Re-ranking (선택)
                        ↓
                  Top-K 선정
                        ↓
                LLM에 Context 전달
```

## 4. BM25란?

**BM25**는 검색어가 문서에 얼마나 중요하게 나타나는지를 계산하는 대표적인 키워드 검색 알고리즘이다.

- 검색어가 문서에 등장하는 정도를 고려한다.
- 여러 문서에서 흔히 나오는 단어보다 상대적으로 희귀한 단어를 중요하게 평가한다.
- 문서 길이를 보정한다.

> 지금 단계에서는 BM25 수학 공식을 외울 필요는 없다.

## 5. RRF란?

두 검색 결과를 합친 뒤 **최종 검색 순위를 결정하는 방법** 중 하나다.

| 문서 | Vector 순위 | BM25 순위 |
|---|---:|---:|
| A | 1위 | 3위 |
| B | 2위 | 없음 |
| C | 3위 | 1위 |
| D | 없음 | 2위 |

- Vector의 Cosine Similarity와 BM25 점수는 **척도가 다르므로 그대로 더하면 안 된다.**
- **RRF(Reciprocal Rank Fusion)**는 원래 점수 대신 각 검색 결과의 **순위**를 활용해 하나의 순위로 통합한다.
- RRF의 구체적인 계산 방식은 **37일 차**에 학습한다.

## 6. 꼭 기억할 네 가지

| 용어 | 한 줄 요약 |
|---|---|
| **Vector Search** | 의미가 비슷한 문서를 찾는다. |
| **BM25** | 검색어가 중요한 문서를 찾는다. |
| **Hybrid Search** | Vector와 BM25 검색을 함께 사용한다. |
| **RRF** | 두 검색 결과의 순위를 하나로 합친다. |

**핵심:** Hybrid Search는 **RAG의 검색 정확도를 개선하기 위한 검색 전략**이다.
