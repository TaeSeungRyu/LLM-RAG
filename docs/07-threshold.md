# 07. Threshold와 Top-K

## 개념
- **Threshold**: 검색 결과에 포함할 최소 유사도 기준
- **Top-K**: 최대로 반환할 검색 결과 개수

## 목적
관련 없는 문서를 줄이고 LLM에 전달할 자료의 양을 제한합니다.

## 동작 과정
```text
유사도 계산 → 높은 순 정렬 → Threshold 미만 제외 → 상위 K개 선택
```

## 예시
Threshold `0.6`, Top-K `3`이면 0.6 이상인 문서 중 최대 3개를 반환합니다.

## 핵심 요약
- 조건을 만족하는 문서가 없으면 LLM 호출을 생략할 수 있습니다.
- `0.6`은 예시일 뿐, 모델·문서·질문에 맞게 실험해야 합니다.
- 임계값이 높으면 유용한 문서도 누락될 수 있습니다.
