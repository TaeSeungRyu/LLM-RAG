# 08. Chunking과 Overlap

## 개념
- **Chunk**: 긴 문서를 나눈 작은 조각
- **Chunking**: 문서를 작은 단위로 나누는 작업
- **Chunk Size**: 조각의 최대 크기
- **Overlap**: 인접 조각이 공유하는 중복 부분

## 목적
긴 문서 전체보다 질문에 관련된 부분을 검색하기 쉽게 만들고, LLM에 전달하는 불필요한 내용을 줄입니다.

## 동작 과정
```text
긴 문서 → Chunk 1 / Chunk 2 / Chunk 3
각 Chunk → embeddinggemma → SQLite(원문 + 벡터)
질문 → 유사한 Chunk 검색
```

## Overlap 예시
```text
Chunk Size = 100글자, Overlap = 20글자
첫 Chunk: 0~99번째 문자
다음 Chunk: 80~179번째 문자
```

## 핵심 요약
- Overlap은 의미를 직접 판단하는 기술이 아니라 **일부 내용을 겹쳐 문맥 손실을 줄이는 방법**입니다.
- Chunk가 너무 작으면 문맥이 끊기고, 너무 크면 불필요한 정보가 늘어날 수 있습니다.
- 현재 실습은 문자 수 기준 분할이며, 실제 서비스에서는 문장·문단·토큰 단위도 고려합니다.
