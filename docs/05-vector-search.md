# 05. 벡터 검색 (Semantic Search)

## 개념
질문 벡터와 문서 벡터를 비교하여 의미적으로 관련된 문서를 찾는 방식입니다.

## 목적
키워드가 정확히 일치하지 않아도 유사한 내용을 검색합니다.

## 동작 과정
```text
[사전 준비] 문서 → Embedding → SQLite(원문 + 벡터)
[검색] 질문 → Embedding → 저장된 벡터와 비교 → 점수 정렬 → 원문 반환
```

## Cosine Similarity
두 벡터의 방향 유사도를 측정합니다.

```text
cos(A,B) = (A·B) / (|A|×|B|)
```

## 핵심 요약
- 일반적으로 점수가 높을수록 의미적으로 관련성이 높습니다.
- 점수 `0.8`은 정답 확률 80%라는 뜻이 아닙니다.
- 실습에서는 SQLite에서 벡터를 읽고 **TypeScript 코드에서** 유사도를 계산했습니다.
- 이 단계에서는 LLM에 질문하지 않고 검색 결과만 반환합니다.
