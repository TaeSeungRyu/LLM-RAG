# 04. Embedding

## 개념
Embedding은 텍스트를 의미 비교에 사용할 수 있는 숫자 배열(벡터)로 변환하는 과정입니다.

## 목적
표현이 달라도 의미가 비슷한 문서를 찾기 위해 사용합니다.

## 동작 과정
```text
"나는 개발자입니다" → embeddinggemma → [0.12, -0.45, ...]
```

## 핵심 요약
- 실습 모델: `embeddinggemma`
- 문서와 질문을 **같은 Embedding 모델**로 벡터화해 비교합니다.
- Embedding 모델은 자연어 답변을 생성하는 LLM 역할을 하지 않습니다.
- 같은 모델이라도 벡터 점수 자체가 정답 확률을 뜻하지는 않습니다.
